# Itálico por palavra (2º modelo + inclinação) — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Detectar itálico palavra a palavra com precisão ≥ 90%, combinando o itálico do dots, um
2º VLM que só marca e a inclinação medida na imagem, rodando os dois modelos numa GPU só.

**Architecture:** Depois do OCR (etapa 1, dots), cada bloco de texto vira uma lista de *tokens*
com três evidências: itálico do dots, inclinação medida por palavra (caixas de palavra casadas com
os tokens) e, para blocos suspeitos, a marcação do 2º modelo (texto idêntico, com `<i>…</i>`). A
fusão (R1 ou R2) decide token a token; o `assemble` aplica as marcas aos `Span`. Um "trocador"
alterna os servidores: sleep/wake (modo C, padrão) ou reinício pela própria app (modo A).

**Tech Stack:** Python ≥ 3.11, numpy, Pillow, httpx, vLLM 0.17.1 (via `uvx`), pytest, pypdf (dev).

**Spec:** `docs/superpowers/specs/2026-10-21-titulo-italico-design.md` (seções "Item 5", "Execução
na GPU", "Gabarito e avaliação", "Critérios de aceite").

**Depende de:** Task 1 de `docs/superpowers/plans/2026-10-21-titulo-e-formato.md` (medidas
recalculadas da imagem; `tests/synth.py` com `make_pdf`, `FakeEngine`).

## Review Focus

1. Página torta (Horkheimer): inclinação medida contra o eixo da imagem marcaria tudo como
   itálico; deve ser medida contra a linha de base de cada linha (Task 2, imagem girada 1,5°).
2. Hifenização no fim da linha e pontuação/aspas/chamadas de nota coladas ("Versão¹", "“Em",
   "ouro”,"): o casamento não pode desalinhar o resto do bloco (Task 3).

   vale o dots (Task 4).

   par; o cache da etapa 1 fica salvo e a nova execução não refaz o OCR (Task 7).
5. Notas de rodapé (região dividida em várias notas, rótulo "¹" separado): o cursor de tokens não
   pode desalinhar entre as notas (Task 7).

  - `SleepSwitcher(roots: dict[str, str], client: httpx.Client | None = None)` — `roots` sem `/v1`

    modo C os servidores sobrevivem entre execuções).

    executa `[script, modelo, porta]` (`start_new_session=True`, saída em `log_dir/<papel>.log`);
    espera `GET http://127.0.0.1:{porta}/v1/models` = 200; processo morto ou tempo esgotado →
    `RuntimeError` com as últimas 20 linhas do log. `close()` derruba o que estiver no ar.
  - `default_script() -> Path` — `scripts/serve_vllm.sh` do repositório
    (`Path(__file__).resolve().parents[2]`); erro claro se não existir.
  - `ITALIC_HF_MODEL = "Qwen/Qwen3-VL-8B-Instruct-FP8"` (provisório; definido na Task 10).
  - `serve_vllm.sh`: `--host "${HOST:-127.0.0.1}"` sempre; com `SLEEP_MODE=1`, acrescenta
    `--enable-sleep-mode --mm-processor-cache-gb 0` e exporta `VLLM_SERVER_DEV_MODE=1`.
  - `serve_pair.sh [modelo_italico]`: sobe o dots na 8000 (`SLEEP_MODE=1`, em segundo plano, log em
    `${LOG_DIR:-/tmp}/ocrpdf-ocr.log`), espera ficar pronto, faz dormir, sobe o 2º modelo na 8001,
