# Editor do document.json (`ocrpdf edit`) — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Um editor local no navegador para ajustar à mão o `document.json` de uma página do original por vez, com resultado ao lado e renderização da página e do documento.

**Architecture:** Campos novos no modelo e no render (ocultar, linhas em branco, negrito/itálico do bloco, formato do PDF gravado, caminho do original). O núcleo do editor é Python sem HTTP (`EditSession`: JSON compacto por página, validação, gravação; `rendering`: imagens das páginas). Um servidor `ThreadingHTTPServer` expõe isso numa API JSON; a página é HTML + JS puro.

**Tech Stack:** Python ≥ 3.11 (biblioteca padrão `http.server`, `json`, `webbrowser`), WeasyPrint e pypdfium2 (já dependências), HTML/CSS/JS sem bibliotecas.

**Spec:** `docs/superpowers/specs/2026-10-21-editor-design.md`

## Review Focus

1. **JSON quebrado ou com estrutura mudada** (vírgula faltando, bloco apagado, `kind` trocado, campo
   com erro de digitação como `"algin"`): nada é gravado e a mensagem diz a linha ou o bloco.
   → Tasks 3 e 4.
2. **Trocar de página com edição não salva**: a edição não some sem aviso. → Task 4 (memória do
   servidor) e Task 7 (pergunta Salvar/Descartar/Ficar).
3. **Tamanho da fonte num documento com "corpo" na faixa** (Marx: medido 51,5, saída 12,4): o campo
   da barra mostra e grava na escala certa. → Task 4.
4. **Bloco oculto com chamada de nota ou com `trailing_notes`**: notas só dele somem; as ancoradas
   nele continuam saindo. → Task 1.
5. **Clique duplo em "Renderizar tudo" num livro grande** (Horkheimer, dezenas de segundos): a
   segunda renderização é recusada, não corre em paralelo. → Task 6.

1ª faixa: ◀ página N de M ▶ (N = `pages[i] + 1`), **Salvar**, **Renderizar esta página**,

parágrafo**, **Quebra de página antes**, **− linha** / **+ linha em branco antes**, **Tamanho (pt)**,
**Ocultar/Mostrar bloco**. Esquerda: `<textarea>` com numeração de linhas. Direita: abas **Resultado** e
**Original** (imagem com os blocos numerados por `box`; ocultos tracejados e riscados; o do cursor em
